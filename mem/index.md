# Project Memory

## Core
Deux comptes Gmail intégrés : mr.allanklein@gmail.com (perso) et pro.allanklein@gmail.com (pro), avec sélecteur dans la Boîte mail.
Esthétique : liquid glass (flou + grain), ombrage/surbrillance au clic, textes plus gras et lisibles. Éviter l'omniprésence du jaune/or.
Les tâches sont rattachées à un projet ; les tâches annexes vivent dans la to-do list libre.
Couleurs d'états projets : gris (Pas commencé, Archiver), or (Écriture, En cours), rouge (Tournage), violet (Montage), bleu (Validation), vert (Publier, Terminé).
Calendrier inspiré d'Apple Calendar : évènements visibles dans la grille, jours cliquables, création/édition Google Agenda.
Les profils s'appellent « Espaces » (table spaces) : nombre illimité, chacun avec nom, étiquette, photo, bannière, ville météo, boîtes mail et agendas Google propres.
Boîte mail : UI inspirée de Notion Mail (sidebar vues + sélecteur de compte avec avatars).
