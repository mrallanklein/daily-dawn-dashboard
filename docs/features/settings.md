# Réglages et espaces

Accessible depuis l'avatar de la barre latérale.

## Ce que l'utilisateur peut faire

- Créer un espace, le renommer, définir son étiquette, le réordonner, le
  supprimer.
- Changer l'avatar et la bannière d'un espace.
- Basculer d'espace actif.
- Activer / désactiver les comptes mail de l'espace.
- Choisir les agendas affichés pour l'espace.
- Définir la ville météo via la géolocalisation.
- Choisir le thème : clair, sombre, ou automatique selon l'heure.
- Se déconnecter.

## Règles fonctionnelles

- L'espace actif est mémorisé entre les sessions.
- Le mode automatique applique le thème sombre la nuit (20 h – 7 h) et le thème
  clair le jour ; un choix manuel prime jusqu'au prochain changement.
- La suppression d'un espace supprime ses données métier.
- L'authentification se fait par compte Google.
